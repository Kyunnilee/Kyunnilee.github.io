Can VLMs turn what they see about physics into actions that work?

TL;DR

We build APRO, a simulator benchmark that tests whether VLMs can use physical reasoning to act, not just answer questions about physics.

480 items, 11 tasks, 3 regimes: infer properties, predict from past trials, and adapt through interaction.

Models get better with evidence, but turning that into successful robot actions is still hard.

Paper · Code · Dataset

Motivation

A robot picks up a hammer and it tilts. That tilt tells it where the mass is, so it should grasp somewhere else before swinging.

Existing benchmarks test either physics understanding (fixed images, no action) or task success (no view into why it failed). We want both, in one loop.

Three regimes

  • R1 · Infer — predict a physical property from one observation.
  • R2 · Predict from experience — see earlier trials, then predict a new one.
  • R3 · Adapt — act, get feedback, try again until the goal is reached.
Oracle setting. We can also hand the model ground-truth simulator values (mass, friction, …), step by step. This separates "didn't know the physics" from "couldn't use it".

The benchmark

Setup
  • Size: 480 items, 11 tasks, 3 simulators (MuJoCo, Isaac Sim, OmniGibson).
  • Models: GPT-6 Sol, Gemini 4 Argon, Gemini 3.8 Flash, Claude Opus 5.5, Qwen3.5-27B, Qwen3.5-9B, DeepSeek-VL2.
  • Robots (R3 tools): Franka Panda + gripper, KUKA iiwa + Sharpa hand.

Takeaways

  1. Models can infer physics, but struggle to act on it.
  2. Past trials help most at the start.
  3. Giving the true physics helps prediction, but not always manipulation — execution is the bottleneck.
Limitations. Simulation only; few tool tasks; no human baseline.
